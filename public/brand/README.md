# Fable brand

- `fable-mark.svg` — logo mark (speech bubble with an approved check). Use at 16px and up.
- `fable-logo.svg` — mark plus wordmark.

Colors

| Token | Hex | Use |
| --- | --- | --- |
| Navy | `#1b2559` | Logo tile, headings, wordmark |
| Indigo (primary) | `#2b3a8f` | Buttons, links, active states |
| Indigo light | `#eef1fb` | Tints, selected backgrounds |
| Amber (accent) | `#f4a61d` | Check mark, highlight CTAs |
| Slate | Tailwind slate scale | Text and borders |

The in-app scale lives in `app/globals.css` under `--color-brand-*` and `--color-accent-*`.
